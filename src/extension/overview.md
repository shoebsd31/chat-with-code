# Chat with code

Ask questions about the code and documentation in your Azure DevOps repositories and get
answers with links to the exact files and lines.

- Answers come only from your own repositories, indexed by a backend you host.
- Uses your own Azure OpenAI deployment (bring your own key).
- Respects Azure DevOps permissions: people only get answers from repositories they can read.

Find it under **Repos > Chat with code**.
